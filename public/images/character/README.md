# Character image

`character.png` is a **generated placeholder** — the original Mamuu OC drawn
for this project (source: `art/character.svg`, rasterized at 1120×1280).

Drop the real illustration here as `character.png` (or `.webp` and update
`portfolio.characterImage` in `src/data/portfolio.js`). If `characterImage`
is `null`, the About section renders the inline SVG character from
`src/components/CharacterPortrait.jsx`.
